# Built-in skills

These skills come from [boldsoftware/shelley](https://github.com/boldsoftware/shelley),
Copyright 2026 Bold Software, Inc., licensed under the Apache License 2.0.
They are vendored here unchanged so a Clojure Shelley has the same skill
library available; `resources/skills/*/SKILL.md` may be edited freely.

Their contents describe the original Go runtime in places (database paths,
cli names). Treat them as a starting library, not as documentation for this
implementation.
